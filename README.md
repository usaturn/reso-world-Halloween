# Halloween Magical Carnival 〜おばけたちの夜祭り〜

Resonite のハロウィン用ワールドを、[resoloop](https://github.com/orange3134/resoloop) と Blender で作るプロジェクト。

- 全体の仕様と工程: [Issue #1](https://github.com/usaturn/reso-world-Halloween/issues/1)。作業は Issue #1 の子 Issue ごとに進める
- コンセプトアート: [concept_art/](concept_art/)。雰囲気の参考で、寸法図ではない。Issue #1 の仕様と配置データを優先する
- 作業環境: [create-reso-world](https://github.com/usaturn/create-reso-world) の Dev Container。このリポジトリはその `worlds/reso-world-Halloween/` に置き、規約は [AGENTS.md](AGENTS.md) に従う
