## 実装上の注意

- 画像は**ビジュアルと構成の参考資料**であり、正確な寸法図、座標図、Meshではありません。
- エリアの配置は **中央広場＋北（屋敷）＋東（キャンディ）＋南（遊園地）＋西（森）** を優先して統一してください。
- 世界観は「怖すぎない、かわいく楽しいハロウィン」。色彩はオレンジ・紫・エメラルドグリーンを中心にします。
- 詳細な仕様・優先順位・Meshyによる手動制作対象（最大8個）は、別途ワールドSpecを正としてください。
- 画像内の装飾すべてを忠実に再現する必要はありません。自動アニメーションの豊かさとVRでの動作負荷のバランスを優先してください。
- `02_world_layout_guide.png` の英語ラベルは補助表示です。地形や建物の正確な寸法・座標は実装時に設計してください。
