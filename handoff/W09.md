## 4. 再実行手順

プロジェクト（worktree）のディレクトリで実行する。

```sh
resoloop blender run modeling/meshy/intake_inspect.py --json      # measured と derived を書き直す（約 45 秒）
resoloop blender run modeling/meshy/review_views.py --json        # review/meshy/<row_id>_views.png（約 1 分）
resoloop blender run modeling/meshy/finish.py --arg=--row --arg=<row_id> --arg=--name --arg=<M>_<AssetName>_001 \
  --arg=--output-dir --arg=<存在しない出力先> --json                 # 1 行の仕上げ
resoloop blender export <出力先>/<name>.blend --output <出力先>/bundle --parent <Slot> --preserve-hierarchy --pack-pbr --json
resoloop validate <出力先>/bundle/model.apply.json --offline --json
uv run pytest
```

`decided` を変えたら `intake_inspect.py` を実行し直す（`tests/test_meshy_received.py` が食い違いを検出する）。原本の一式が変わったら、#13 の最新の確定コメントから `source` を作り直す。
