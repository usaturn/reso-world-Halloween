## 6. 文字盤の計測と W06 の針・W09 の点との照合

方法: 仕上げたメッシュに +Y の前から -Y 向きのレイを当てる（`checks.json` の `dial.method`）。中心は、平らな内側の円盤から数字の帯へ上がる段（半径約 0.6 m の円）を 120 本の放射線で拾い、円に当てはめた（数字が段に触れる所は外す。115 点中 81 点、残差 4.4 mm）。外径は、最初に当たる面が文字盤の面より 8 cm 奥（周りの壁）になる半径を方向ごとの中央値で読んだ。

| 項目 | 値 |
|---|---|
| 文字盤の中心 | **(0.0015, 0.3539, 8.032)**（x, y = 文字盤の面, z = 地面からの高さ） |
| 外径 | 左右 **2.308 m**（+X 1.149、-X 1.159）、上下 2.338 m（上 1.171、下 1.167）。わずかに縦長 |
| 面の向き | 法線 (-0.00082, 1.0, -0.00157)、+Y からの傾き 0.10°。正面（+Y）向きの鉛直の面 |
| 内側の円盤 | 面は y 0.354 の平面（半径 0.12〜0.50 m の凹凸は最大 2.2 mm）、数字の帯との段の半径 0.603 m |
| 数字の帯・縁 | 浮き彫りで、面から最大 2.4 cm（y 0.378）、縁は最大 y 0.379 |
| 軸受け | 中心 (0.0049, 8.067)、半径約 5.6 cm、前面 y 0.406。**文字盤の中心から 3.5 cm 上にずれている**（Meshy の形のまま） |

目で見た確かめ（`M07_dial_textured.png` の右）: 計測した外径と段の円（マゼンタ）は、描かれた金の外縁と内側の輪にほぼ重なる。描かれた輪は計測の円より 0〜1.5 cm 上に中心がある程度で、中心の確からしさは ±1.5 cm。黄色の点が軸受けの中心、水色の点が W06 の針の回転軸。

W09・W06 との照合:

- W09 の `dial_centre_face` (0.001, 0.364, 8.095) は、計測した中心より **z が 6.3 cm 高い**（y は 1.0 cm 前）。W09 が書いた点の誤差（置いた後 ±0.074 m）の中だが、針の軸に使うには大きい
- W09 の `dial_rim_top_front` の y 0.556 は文字盤の縁ではなく、文字盤の上の軒（z 約 9.45〜9.65 m で y 0.50〜0.60 まで出る）を読んだ値と見られる。文字盤の縁の前面は y 0.379 以下。外径 2.29 m は計測の 2.308 m とほぼ一致

## 9. P2 で差し替えるときの注意

- **差し替え先**: W06 の仮モデル `EFR_ClockTower_001` の本体 `EFR_ClockTower_001_Body`（Spec §6.3 の VisualRoot）の中だけ。アセット一覧の `replacement.replaces_placeholder` に、W06 のアセット一覧から写した差し替える部品・隠す部品（`EFR_ClockTower_001_Dial`）・残す部品（時針・分針・鐘・鐘の腕木とその回転軸）がある。MotionRoot（針と鐘の回転軸）と制御の参照は作り直さない
- **バンドル**: このバンドルは試験用の `--parent Root/ResoLoop_Test_W09_M07` で作った。そのまま apply せず、`blender/M07/M07.blend`（無ければ `build.py` で作るか `finished/M07/M07.blend`）から、検証済みの VisualRoot のパスを `--parent` にして新しい出力先へ export し直す。バンドルの root Slot は `M07`、その下に `M07_ClockTower_001`（位置 0・回転なし・scale 1、`StaticMesh` と `MeshRenderer`）と `Blender_Providers`（`StaticTexture2D` 2 個、`PBS_Metallic` 1 個）
- **原点の合わせ方**: メッシュの原点は岩の台座の底面の中央（z = 0）。W06 の仮の本体は同じ外接箱・同じ原点・同じ正面で作ってあるので、仮の本体と同じ位置（W06 の配置: (-38.5, 0, 0)、Z -90° で正面が東の主動線を向く）に、VisualRoot のローカルの位置 0・回転 0 で入れればよい。Blender の (x, y, z) は Resonite の (x, z, y)。正面（文字盤と階段）は Blender の +Y = Resonite の +Z（Slot の前方）
- **針の軸**: 6 章のとおり、W06 の針の回転軸は文字盤の中心から 6.3 cm 上にある。直してから差し替えるのが望ましい。直さずに差し替えると、針の先が数字に対してずれ、針の根元の下から M07 の軸受けが少し見える
