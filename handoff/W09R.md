## 4. 再実行手順

差し替えの記録 4 章。要点:

1. `docs/p1-handoff.md` 6 章の手順で地区の `.blend` を、`resoloop blender run modeling/<M>/build.py --json` で素材の `.blend` を作る
2. `uv run python modeling/p2_static/export_p2.py --url <URL> --key <地区>`（`REPLACEMENTS` の仮モデルの描画を止めた `p2.apply.json`）
3. `uv run python modeling/p2_meshy/export_meshy.py --url <URL> --meshy <M>`（置き方・光源・カメラだけを変えるときは `--recompose <既存のバンドル>`）
4. スナップショット（`resoloop import`）→ diff で対象を確かめる → apply（素材は `--texture-transfer data`）→ 2 回目の diff・apply が 0
5. `uv run python modeling/p2_meshy/verify_live.py --url <URL> --raw-out <Git の外> --output review/p2_meshy/live_checks.json`

state は親の checkout の `/workspaces/reso-world/worlds/reso-world-Halloween/.resoloop/state/`（`p2m_M02.json` を足した）。消すと次の apply が同じ物をもう一度作るので消さない。スナップショットと diff・apply の報告は親の checkout の `tmp/w09r/`（Git の対象外）。

## 6. 残りの 7 素材の子へ

### 6.1 子の分け方の案

同じワールドへ apply するのは 1 つのセッションだけで、どの子も `modeling/p2_meshy/replacements.py` の `REPLACEMENTS` に行を足すので、**1 件ずつ順に**進める（前の子を `blocked_by` にする）。Spec §5.2 の順で、地区ごとに 1 件:

| 案のキー | 素材 | 地区 | 主な作業 |
|---|---|---|---|
| W09R-A | M01 入場ゲート | A | アーチと門扉 2 枚。門扉は可動部品 |
| W09R-B | M03 幽霊屋敷 | B | W03 の扉・玄関ホール・ポーチの階段を M03 の開口に合わせる |
| W09R-C | M04 お菓子工房、M08 魔女 | C | M04 は窓の発光の画像、M08 は空中の物（当たり判定なし） |
| W09R-D | M05 屋根・中央の柱、M06 先頭車 | D | 回転・移動する部品の下。W05 の支柱を伸ばす、前照灯の取付位置 |
| W09R-E | M07 時計塔 | E | 本体と仮の文字盤。針の軸のずれ |

方式を早く固めたいときは、A より C（静的な建物と空中の物で、地区の造形を変えない）を先にしてもよい。

### 6.2 素材ごとの注意

- 共通: `REPLACEMENTS` の行（`visual_root`・`hide`・`rotation_z_deg`・`position_local`・`cameras`）を足し、地区を export し直して diff の対象が足した仮モデルの描画だけかを確かめる。`hide` は `visual_root` かその子孫だけ（`hide_placeholders` が止める）。取付位置が `visual_root` の子なら、目印の描画を止めるか撮影で確かめる。仕上げた素材の ID・向きは `docs/p1-handoff.md` 5 章と 8 章の 6〜8、各 `handoff/W09-<M>.md` 8 章
- M01: 仮モデルの見た目は `APL_EntranceGateProxy_001_Arch`。門扉 `_DoorLeft`・`_DoorRight` は可動部品（仮モデルは Z ±88° に開いた形）で、M01 の門扉は回転 0 で閉じ、左 +90°・右 -90° で内側へ開く（`docs/p1-handoff.md` 8 章の 4、`handoff/W09-M01.md`）。門扉は可動部品の root を作り直さずに、その下に置く方法を決める。両面化した門扉の三角形の増加と、開いた門扉の間 3.909 m（利用者が受け入れた）
- M03: 仮モデルの Slot `BMN_MansionPlaceholder_001`（`FixedCollision` は地区の root の下の兄弟）。W03 の扉・玄関ホールを x +0.3725 m・z +0.091 m 動かし、扉の高さを 2.592 m、ポーチの階段の上端を z 1.870 にする（`docs/p1-handoff.md` 8 章の 1。W03 の所有ファイルの最小限の修正）。M03 の壁は片面なので、開口の奥を玄関ホールで塞ぐ。建物の当たり判定は仮モデルの形が仕上げた形とどれだけ違うかを撮影と歩行で確かめて決める
- M04: 窓の発光は `PBS_Metallic` の `EmissiveMap`（`handoff/W09-M04.md`）。画像が 3 枚になるので `--texture-transfer data` の時間を見込む
- M05: 屋根と柱は回転する `TurnRoot` の下（当たり判定なし）。W05 の支柱の上端が屋根の下面より 0.58〜0.96 m 低い（`docs/p1-handoff.md` 8 章の 2）
- M06: `EngineRoot` の下（動く列車、当たり判定なし）。前照灯の取付位置をレンズの前へ（8 章の 3）
- M07: `EFR_ClockTower_001_Body` と仮の文字盤 `_Dial` を差し替える。M07 の文字盤の中心は W06 の針の軸より 6.3 cm 下（`handoff/W09-M07.md`）。針は可動部品で、原点を変えるときは利用者に確かめる
- M08: `CCD_M08_FlyingWitchProxy_001`（当たり判定なし、P3 で飛ぶ）。ほうきの柄の向きは W09 の軸と違う（`handoff/W09-M08.md`）
