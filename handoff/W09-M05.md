## 4. 再実行手順

プロジェクト（worktree）のディレクトリで実行する。原本のコピー（`received.json` の `copy_path`）が要る。

```sh
resoloop blender run modeling/M05/build.py --json   # .blend・テクスチャ・checks.json・確認画像・アセット一覧（約 100 秒）
uv run python modeling/M05/export.py                # export（exports/M05/bundle を作り直す）・validate・export_result
uv run python tools/check_data.py --key M05
uv run python tools/check_blend.py --key M05
uv run pytest
```

- `--arg=--skip-review` を付けると確認画像を作らない（`checks.json` の `backface_check`・`uv_texel_share_1024` も出ない）
- `build.py` を実行すると `export_result` が `unexported` に戻るので、`export.py` は最後のビルドの後に実行する
- 新しい checkout では、`build.py` を実行するまで `check_data.py --key M05` が終了コード 1 になる（`.blend` とテクスチャをコミットしないため。M02 の handoff 6 章の要望と同じ）。全体の `check_data.py` も、ほかのキー（M01・M02 など）の `build.py` を実行していない checkout では 1 になる（この worktree で確認。`--no-file-check` を付ければ 0）
- `docs/conventions.md` §7.5 の `--root-path` は resoloop 0.2.0 には無い。`--parent` と `--pack-pbr` を使う（W09・M01・M02 の handoff と同じ）

## 8. P2 で差し替えるときの注意

- **差し替え先**: D 南・遊園地のメリーゴーラウンドの `AssetRoot/MotionRoot/VisualRoot`（Spec §6.3）の VisualRoot の中だけ。回転床（G13）の MotionRoot と制御の参照は作り直さない。W05 の仮モデルの中央の柱と屋根（ID は W05 が決める。2026-10-31 時点で未マージ）と入れ替える
- **バンドル**: このバンドルは試験用の `--parent Root/ResoLoop_Test_W09_M05` で作った。そのまま apply せず、`blender/M05/M05.blend`（無ければ `build.py` で作るか `finished/M05/M05.blend`）から、検証済みの VisualRoot のパスを `--parent` にして新しい出力先へ export し直す（`export.py` の `PARENT` を変えるか、同じ旗で `resoloop blender export` を実行する）。バンドルの Slot は `M05` → `M05_PumpkinCarousel_001`（位置 0）→ `M05_Canopy_001`（Resonite の位置 (0, 2.964, 0)）と `M05_CenterCasing_001`（位置 0）、どちらも回転なし・scale 1 で `StaticMesh` と `MeshRenderer` を持つ。ほかに `Blender_Providers`（`StaticTexture2D` 4 個、`PBS_Metallic` 2 個）
- **原点の合わせ方**: `M05_PumpkinCarousel_001` の原点は回転軸上の柱の底。回転床の上面の軸上（作業中の W05 では TurnRoot の z 0.19 の取付点）に置けば、屋根は自動で 2.964 m 上に来る。屋根と柱を別の取付点に分けて置く場合は、それぞれの Slot の位置を 0 にして、屋根の取付点を柱の取付点の真上 2.964 m にする。Blender の (x, y, z) は Resonite の (x, z, y)。正面（顔と紋章）は Blender の +Y = Resonite の +Z。屋根は回るので向きは基準の姿勢の定義で、ワールドの向きは W05 が決める（W09 の推奨は `placement_hint.rotation_z_deg` -90）
- **回転**: 屋根は回転床と一緒に回す前提（W09）。柱を回すかどうかは W05 が決める（作業中の W05 は TurnRoot の下に置いている）。回転と上下動の仕組みは P3 で付け、この見た目の Slot を直接回さない
- **発光**: アルベドに発光は焼き込んでいない（材質の `EmissiveColor` は 0、発光の画像なし）。顔の目・口と飾り帯の電球は色の画像に描かれた明るい色で、光らせるなら Resonite 側で発光の材質か光源を別に足す（本体の材質と共有しない。全体が光る）
- **コライダー**: この見た目にはコライダーを含めない。柱と回転床の当たり判定は W05・P2 が FixedCollisionRoot・LogicRoot 側で作る。屋根は手が届かない高さ（垂れ飾りの最下点 3.045 m）
- **負荷の目安**: 三角形 74233（屋根 41819・柱 32414）、画像 4 枚で RGBA8 とミップの見積もり合計 約 35 MB（export の値。Resonite での実測ではない）。`report.json` は 5 万三角形を超える警告を出す。W09 は削減しないと判断した（削減と焼き直しで UV と色が崩れる危険を避けた）。P2 で負荷が問題になれば、W09 の `docs/meshy-intake.md` の削減の手順を使う
