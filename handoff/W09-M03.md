## 4. 再実行手順

プロジェクト（worktree）のディレクトリで実行する。原本のコピー（`received.json` の `copy_path`）が要る。

```sh
resoloop blender run modeling/M03/build.py --json   # .blend・テクスチャ・確認画像・checks.json・アセット一覧（約 2 分）
resoloop blender run modeling/M03/build.py --json   # 2 回目（受け入れ基準）。出力は 1 回目と同じ
uv run python modeling/M03/export.py                # export・validate・export_result（最後の build の後に実行する）
uv run python tools/check_data.py --key M03
uv run python tools/check_blend.py --key M03
uv run pytest
```

- `build.py --arg=--skip-review` は確認画像・`checks.json`・アセット一覧を書かない速い再生成（約 20 秒）
- build はアセット一覧の `export_result` を `unexported` に戻す（`.blend` が変わるとバンドルと合わなくなるため）。export は最後の build の後に `export.py` で行う
- 新しい checkout では、`build.py` を実行するまで `check_data.py --key M03` が終了コード 1 になる（`.blend` をコミットしないため。M01・M02 と同じ）
- `docs/conventions.md` §7.5 の `--root-path` は resoloop 0.2.0 には無い（W09 の handoff と同じ）。`export.py` は `--parent Root/ResoLoop_Test_W09_M03` を使う。金属・粗さの画像があるので `--pack-pbr` も要る
