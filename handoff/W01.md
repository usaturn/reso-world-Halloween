## 9. 残課題・W02〜W07 が知るべき注意点（W07 への修正依頼を含む）

1. **W02〜W06（エリア実装担当）への注意点**:
   - **エリア JSON (`layout/areas/<key>.json`) とマニフェスト (`assets/manifest/<key>.json`) の `key` / `area_id`**:
     `uv run python tools/check_data.py` は `VALID_KEYS` / `VALID_AREA_IDS` として `A_plaza`, `B_alley`, `C_park`, `D_mansion`, `E_forest` を検査する。各子 Issue で指定された自身の所有ファイルパスと `tools/check_data.py` の挙動を確認し、`layout/world_layout.json` の `area_key_mapping` を参照して座標・境界・接続点を取得すること。
   - **地形・道路との高さ合わせ**:
     `world.blend` 側で各島のベース地面（A, C, D, E は上面 `z = 0.0m`、B の北台地は上面 `z = +1.5m`）と主幹道路デッキ（上面 `z = 0.06m`、北台地は `z = 1.56m`）を生成している。各エリアの建物・小物は各エリアの `ground_elevation_m`（A/C/D/E は `0.0m`、B は `1.5m`）を基準に配置し、主幹道路の中央通路（幅 3.5m〜4.0m）および南正面入り口の視線誘導コリドー（`x = -2.0..+2.0`）を塞がないこと。
   - **`append_common_part` 使用時の `.001` マテリアル重複排除**:
     `modeling/lib/common_parts.py` の `append_common_part` で `common.blend` から異なる種類の共通部品を複数回読み込むと、Blender が共有マテリアル（`MAT_CMN_WroughtIron` など）に `.001` サフィックスを付与し、`tools/check_blend.py` でエラーになる。`modeling/world/build.py` の `_deduplicate_imported_materials()` と同様に、`save_blend()` 前に `.NNN` マテリアルをベース名マテリアルへ再割り当てして削除すること。

2. **W07（全体統合・検査・修正担当）への引き継ぎ・修正依頼**:
   - **`tools/check_data.py` のエリアキー名**:
     W00 作成の `tools/check_data.py` では `VALID_KEYS` / `VALID_AREA_IDS` が `B_alley`, `C_park`, `D_mansion` になっているが、親 Issue #1 および W03〜W05（#5〜#7）の仕様では `B_mansion`, `C_candy`, `D_amusement` が使われている。W07 で `tools/check_data.py` および `tools/check_blend.py` の `VALID_KEYS` / `VALID_AREA_IDS` / `COLLECTION_NAME_PATTERN` が両方のキー名を受け入れるように更新すると、全エリアの統合がより明確になる。
   - **`modeling/lib/common_parts.py` のマテリアル重複防止**:
     `append_common_part` 内で `bpy.data.libraries.load` 実行後に `.001` マテリアルを既存の同名マテリアルへ統合する処理を `modeling/lib/common_parts.py` に入れることを推奨する。
   - **`blender/probe/probe.blend` のテクスチャ絶対パス問題**:
     W00 が生成した `blender/probe/probe.blend` 内の画像 `p0_asym_test.png` の `filepath` に、削除済みの W00 worktree の絶対パス（`/workspaces/reso-world/worlds/reso-world-Halloween-W00/blender/probe/textures/p0_asym_test.png`）が記録されている。画像は `.blend` 内に pack されているものの、`tools/check_blend.py` は `raw_path` が空でない場合に `packed_file` の有無にかかわらずディスク上のファイル実在を検査するため、W00 worktree が存在しない環境で `probe.blend` の検査が失敗する。W07 にて `modeling/probe/build.py`（または `modeling/lib/scene.py` の `save_blend` で `relative_remap=True`）を再実行して `probe.blend` のパスを相対化するか、`tools/check_blend.py` で `img.packed_file is not None` の場合は外部ファイル欠落とみなさないよう修正されたい。
