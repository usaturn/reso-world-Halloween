## 8. P2 で差し替えるときの注意

- **差し替え先**: C 東の上空を巡回する魔女（G11）の `AssetRoot/MotionRoot/VisualRoot`（Spec §6.3）の VisualRoot の中だけ。巡回で動かす MotionRoot と制御の参照は作り直さない。W04 の仮モデル（作業中の ID は `CCD_M08_FlyingWitchProxy_001`。2026-10-31 時点で `main` に無いので、P2 で `main` のアセット一覧を確かめる）と入れ替える
- **バンドル**: このバンドルは試験用の `--parent Root/ResoLoop_Test_W09_M08` で作った。そのまま apply せず、`blender/M08/M08.blend`（無ければ `build.py` で作るか `finished/M08/M08.blend`）から、検証済みの VisualRoot のパスを `--parent` にして新しい出力先へ export し直す。バンドルの root Slot は `M08`、その下に `M08_FlyingWitch_001`（位置 0・回転なし・scale 1、`StaticMesh` と `MeshRenderer`）と `Blender_Providers`（`StaticTexture2D` 2 個、`PBS_Metallic` 1 個）
- **原点の合わせ方**: メッシュの原点は飛行の動作中心（ほうきの軸の上、座る位置の下）。VisualRoot を巡回経路の点（MotionRoot の原点）にそのまま置けば、経路が魔女のほうきの軸を通る。Blender の (x, y, z) は Resonite の (x, z, y)。正面（ほうきの先）は Blender の +Y = Resonite の +Z（Slot の前方）なので、MotionRoot の前方を経路の接線に向ける。柄の先の 13° の上がりは姿勢として残してあるので、MotionRoot を傾けない。経路の高さは、原点から下に 0.612 m（ブーツの先）、上に 1.888 m（帽子の先）の広がりで建物との間隔を決める
- **発光**: アルベドに発光は焼き込んでいない（材質の `EmissiveColor` は 0、発光の画像なし）。航跡・発光（Spec の G11）は Resonite 側で別の Slot に付け、本体の材質と共有しない
- **コライダー**: この見た目にはコライダーを含めない。上空を飛ぶので歩行の当たり判定は要らない見込み。触れる・選ぶ操作が要るなら、MotionRoot 側に単純な形のコライダーを別に置く
- **向きの差**: 柄は原点の真上ではなく 4.7 cm -X 側を通り、柄の先は 23° 上がる（6 章）。巡回の高さからは見分けられないが、ほうきの先に何か（光の粒など）を付けるなら、W09 の `broom_tip` (0, 0.91, 0.214) ではなく、測った柄の先の中心 (-0.048, 0.85, 0.208) と先端 y 0.912 を使う
- **負荷の目安**: 三角形 31130、画像 2 枚で RGBA8 とミップの見積もり合計 約 7 MB（export の値。Resonite での実測ではない）
