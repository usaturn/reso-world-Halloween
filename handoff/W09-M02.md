## 8. P2 で差し替えるときの注意

- **差し替え先**: A 中央広場の巨大カボチャの `AssetRoot/MotionRoot/VisualRoot`（Spec §6.3）の VisualRoot の中だけ。MotionRoot と制御の参照は作り直さない。W02 の仮モデル（ID は W02 が決める。2026-10-31 時点で未作成）と入れ替える
- **バンドル**: このバンドルは試験用の `--parent Root/ResoLoop_Test_W09_M02` で作った。そのまま apply せず、`blender/M02/M02.blend`（無ければ `build.py` で作るか `finished/M02/M02.blend`）から、検証済みの VisualRoot のパスを `--parent` にして新しい出力先へ export し直す。バンドルの root Slot は `M02`、その下に `M02_GiantPumpkin_001`（位置 0・回転なし・scale 1、`StaticMesh` と `MeshRenderer`）と `Blender_Providers`（`StaticTexture2D` 2 個、`PBS_Metallic` 1 個）
- **原点の合わせ方**: メッシュの原点は底面の中央（z = 0、平らな底）。VisualRoot を仮モデルの原点（器の上面の中心）に置けば、本体の底が器の上面に乗る。Blender の (x, y, z) は Resonite の (x, z, y)。正面（顔）は Blender の +Y = Resonite の +Z（Slot の前方）。ワールドで顔を南に向けるには、`received.json` の `placement_hint.rotation_z_deg` 180 のとおり Resonite の Y 軸まわりに 180° 回す（W02 が決めた向きを優先）
- **発光（I03 の目の発光）**: アルベドに発光は焼き込んでいない（材質の `EmissiveColor` は 0、発光の画像なし）。発光は Resonite 側で空洞の中に光源か発光の板を置いて付ける（AttachmentPoints）。目から入るレイが当たる内壁は y ≈ -2.2 m（左 -2.196、右 -2.145、高さ z 2.317）、W09 の `interior_back_wall` は (-0.002, -2.409, 0.981)（どれも Blender のローカル座標、m）。発光の材質を本体の材質と共有しない（全体が光る）
- **コライダー**: この見た目にはコライダーを含めない。本体は器の上で手が届かない見込み（W09）。歩行用・操作用の当たり判定は FixedCollisionRoot・LogicRoot 側で W08・P2 が作る。I03 の操作用の物は器の外の正面（+Y）に別に置く（W09 の `split_and_attach`）
- **揺れ**: Spec §7 の反応の小さな揺れは、帽子を含む全体を MotionRoot で動かす（帽子は分けていない）
- **負荷の目安**: 三角形 30792、画像 2 枚で RGBA8 とミップの見積もり合計 約 28 MB（export の値。Resonite での実測ではない）
