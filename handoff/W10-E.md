## 6. 次の子への注意

### 6.1 注意

- **見る人の時刻で動かす物**: `ToLocalTime(UtcNow)` の時・分・秒・ミリ秒（int）から 0 時からの秒を作る（Flux-SDK に `LocalNow` は無い）。drive は見る人ごとに評価されるので、人によって値が違う。同期させたいもの（ショーの段階など）は `WorldTimeDouble` を使う
- **一度だけの演出は、節目からの時刻の関数にする**: τ = N × repeat01(s / N)、x = clamp01(τ / 長さ) で、x = 1 で 0 に戻る式（(1 − x)² をかける）にすると、分岐・インパルス・状態が要らず、途中参加でも鳴り直さない（記録 20.1）。確かめのために節目の間隔を短くする値を置き、確かめた後に戻す
- **同じ材質を共有する物を個体ごとに光らせる**: 物ごとに材質を写し（`district.add_g18_materials`）、その物の MeshRenderer だけを付け替える。同じ材質を使うほかの物（E では池）を、G18 を足す前の宣言（同じ export の `model.apply.json`）の並びと比べて確かめる（`verify_e.declared_materials`）
- **2026-11-03 は observe が遅かった**: 1 回 3〜8 秒（W10-D は 1.5〜5 秒）で、ほとんどが resoloop の CPU の時間。Resonite の中で 1 つの Component を読む間隔も 約 0.15 秒（W10-D は 0.115 秒）。時計で挟む検査は判定しない時計の幅を 1.2 秒にした。速い変化（既定の G18）の細かい照合は、ゆっくりの時刻（`G18Speed` 0.05）で行う
- W10〜W10-D の注意（`handoff/W10.md` 6.1、`handoff/W10-A.md`〜`W10-D.md` 6.1）はどれも変わらない。ワールドを前面に出す、宣言のキーは 10 文字未満、W08 の検査は既知の 11 件、新しい worktree の準備、動いている物は時計で挟んで照合する

  - B（G07 墓石の傾きと戻り、G08 窓からおばけが顔を出して隠れる）: G06 の「閉じたまま・開いたまま」の往復の式（`G06_HOLD`）が使える。G08 は I04（一斉の挨拶）と同じおばけになりそうなので、I04 の値で一斉に出せる形に
  - C（G10 キャンディ製造機の歯車・押出部の連動、G12 ほうきの往復・旋回）: G10 は 1 つの角度から歯数の比で複数の歯車を回す（`Spinner` を歯車ごとに置くより、1 つの式で比を守る）。G12 は G11 の小さい閉じた経路
